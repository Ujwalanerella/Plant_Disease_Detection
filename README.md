# Plant_Disease_Detection_using_cnn
This project focuses on building a Convolutional Neural Network (CNN) model to detect and classify plant species based on leaf images. It leverages deep learning for image classification tasks, helping in applications like agricultural diagnostics and botanical studies.

## Project Structure

- `plant_detection_using_cnn.ipynb`: The core Jupyter Notebook that includes data preprocessing, CNN model building, training, evaluation, and prediction steps.

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- OpenCV
